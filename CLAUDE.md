# CLAUDE.md

Conventions and quick-start for working in this repo with Claude Code.

Defense AI LMS POC — FastAPI backend (`app/`) + React/Vite SPA (`frontend/`).
See `README.md` for the product, `GUIDE.md` for the walkthrough, and
`COMPLIANCE.md` for the PRD requirement mapping.

## The stack

1. **deep-codebase-explorer** — routes any code question between reading files,
   the GitNexus graph, and sub-agent fan-out. Ask naturally; force a mode with a
   prefix (`vanilla:`, `nexus:`, `RLM:`, `ULTIMATE:`).
   **On this machine the graph is unavailable** (see below), so use `vanilla:` /
   `RLM:` / `ULTIMATE:` — `nexus:` will not work.
2. **GitNexus** — call-graph of the codebase. CLI: `npx gitnexus <command>`.
   **Currently not indexed**: the LadybugDB native binary is blocked by a Windows
   Application Control policy. See `.claude/stack-profile.md` → Graph support.
3. **squad-up** — multi-phase agent pipeline. Trigger with `squad up [task]`,
   including plain-English bug reports.
4. **stack-profile** — `.claude/stack-profile.md` (generated by `squad-setup`)
   holds this project's commands, conventions, project type, and high-stakes
   areas. Every agent reads it. Regenerate after a major stack change.

The squad never runs git commands. It edits the working tree and hands you a
ready-to-run commit and PR block at delivery.

No Python type-checker and no frontend linter are configured. Do not invent one
mid-task; propose it as its own change.

## Conventions

- **Component layout.** Backend features live under `app/components/<feature>/`
  with `router.py` / `service.py` / `db_models.py` / `schemas.py`. Follow the
  existing shape rather than introducing a new one.
- **Gateway isolation is a hard rule.** Only `app/gateway/` may import
  `anthropic`, `openai`, or `sentence_transformers`. Everything else goes
  through the gateway factory. `scripts/check_gateway_isolation.py` enforces it —
  run it after any AI/RAG change.
- **Tests.** pytest is installed but the repo has none yet; `scripts/smoke_phase*.py`
  are the real regression net. New tests go in `tests/` mirroring
  `app/components/`, using `pytest-asyncio` + `httpx.ASGITransport` + `aiosqlite`.
- **`devdb.sqlite` is a committed working DB.** Seeding mutates it, so it shows
  up dirty in `git status`. That churn is not part of your diff.
- **Formatting.** The codebase predates `ruff format`; ~52 files are unformatted.
  Do not mass-reformat as part of an unrelated change.
- **Secrets.** `.env` / `.env.dev` hold real provider keys. Never print, log, or
  commit their values.
