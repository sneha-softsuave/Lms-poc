Avoid pure black or near-black UI themes. The user finds them hard to see and wants modern, visibly good themes in lighter colors.

**Why:** In this session the user explicitly said "dont use black" and later asked to switch to "light colors" because the dark theme was hard to see and use.

**How to apply:** When styling the frontend, default to light or deep-slate palettes rather than black/near-black. If proposing theme options, lead with light/non-black choices.
